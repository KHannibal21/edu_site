📚 О пайплайнах и ленивых вычислениях
🎯 Что такое ленивые вычисления?

Вычисления выполняются только когда результат действительно нужен, а не заранее.

⚡ Преимущества для EduPlatform:
  • Экономия памяти - не храним все результаты сразу
  • Быстрый старт - показываем первые результаты немедленно
  • Масштабируемость - обрабатываем потоки любых размеров
  • Интерактивность - студенты видят прогресс в реальном времени
🔧 Используемые подходы:
  • Генераторы (yield) - ленивые последовательности
  • Потоковая обработка - данные обрабатываются по мере поступления
  • Отложенные вычисления - материализация только в конце
  • Топ-K анализ - находим самые сложные задания
💡 Пример ленивого кода:
# Ленивый поток оценивания
grading_stream = lazy_grade_stream(items, answers, rules)

# Обработка по одному результату
for item_id, score in grading_stream:
    print(f"Задание {item_id}: {score}")
    # Можно сразу показывать студенту

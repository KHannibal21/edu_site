📚 О пайплайнах и композиции
🎯 Что такое функциональные пайплайны?

Пайплайны - это композиция функций, где выход одной функции становится входом для следующей.

🔧 Используемые подходы:
  • Замыкания - фабрики функций-фильтров
  • Композиция - последовательное применение функций
  • Чистые функции - предсказуемые преобразования
  • Иммутабельность - работа с кортежами
💡 Пример кода:
# Создание пайплайна
pipeline = compose(
    filter_by_difficulty(2, 4),
    filter_by_topic('python'), 
    transform_to_dict,
    limit_results(5)
)

# Применение
result = pipeline(items)
